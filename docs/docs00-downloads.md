# 00 - Downloads

Download these files before starting the installation. Start Vivado first, it is massive.

## The Big Toolchain

* **Vivado 2020.1:** `Xilinx_Unified_2020.1_0602_1208.tar.gz` (35.51 GB)
  * **Source:** [AMD Archive](https://www.xilinx.com/support/download/index.html/content/xilinx/en/downloadNav/vivado-design-tools/2020-1.html)
  * **CRITICAL:** Must be the "All OS installer Single-File Download". Do NOT use the web installer.

## Required Patches

* **Y2K22 Patch:** `y2k22_patch-1.2.zip`
  * **Source:** [AMD Article 76960](https://adaptivesupport.amd.com/s/article/76960)
* **AR75516 Patch:** `AR75516_vivado_2020_1_1_preliminary_rev1.zip`
  * **Source:** [AMD Article 75516](https://adaptivesupport.amd.com/s/article/75516)

## Board Files

* **PYNQ Image:** `zcu104_v2.7.0.zip`
  * **Source:** [PYNQ Boards](https://www.pynq.io/boards.html) -> ZCU104 -> Previous versions -> v2.7
* **Board CMake:** `cmake-3.27.7-linux-aarch64.tar.gz`
  * **Source:** [GitHub Releases](https://github.com/Kitware/CMake/releases/download/v3.27.7/cmake-3.27.7-linux-aarch64.tar.gz)

## Host Utilities

* **balenaEtcher:** [etcher.balena.io](https://etcher.balena.io/) (To flash the SD card)
